# OsteocyteNetworkConnectivityAnalysis
Code for training and performing connectivity analysis of osteocyte networks. A pre-trained Attention-UNet model is also provided (.pth file)

## Connectivity analysis
In the notebook **connectivity_analysis**, you will find implementation and example of how to run a connectivity analysis on your own dataset using the pre-trained model provided. 

## Training
The python scripts attentionunet and swinunet shows an example of using your own training data and validations to train your own models.
